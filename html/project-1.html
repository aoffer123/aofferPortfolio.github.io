Lead front-end developer

Fooducate

AI-assisted nutrition tracking and meal planning, built around a chatbot nutrition coach.

Year

2022

Tech & technique

React Material UI Firebase GPT API Google Vision AI

Overview

Most meal-planning and diet-tracking tools are cumbersome enough that people give up on them, and personalized nutrition guidance is usually locked behind an expensive dietitian. Fooducate set out to fix both problems: a simple, approachable web app for meal planning and diet tracking, with an AI chatbot nutrition coach built in so personalized guidance didn't require a human on the other end.

This was my senior capstone project at Oakland University, built with a small team. My part covered the front end: architecture, components, and connecting it to the backend, starting from paper wireframes and ending with a fully working, connected app rather than a static prototype.

Key features

  • Dashboard, meal planning, and grocery list views
  • Lifestyle balance goal tracking
  • AI chatbot nutrition coach powered by the GPT API
  • Food photo recognition via Google Vision AI

Technical highlights

  • Integrated the GPT API to power a conversational nutrition coach that gives personalized guidance rather than generic tips
  • Used Google Vision AI so users could log food by photo instead of manual search
  • Structured the app around reusable React components with Firebase for real-time, personalized data

My role

  • Ran competitor research and built paper wireframes before moving into high-fidelity Figma prototypes
  • Built out the front-end architecture and components in React and Material UI
  • Connected the front end to the backend so the app ran on real data, not a static prototype
  • Presented prototypes to stakeholders and iterated through several feedback rounds before development
