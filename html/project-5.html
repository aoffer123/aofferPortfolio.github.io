MARAbio Patient & Provider Portals

HIPAA-compliant portals for a maternal-health blood test provider.

Year

2025

Tech & technique

Remix TypeScript C# / .NET REST APIs HIPAA-compliant infrastructure

Overview

MARAbio develops a blood test that helps detect the likelihood of Maternal Autoantibody Related Autism (MARA) early, in some cases before clinical symptoms exist. I was the lead front-end developer on the two portals that sit around that test: a provider portal where clinicians order blood tests for patients and handle prescription e-signatures, and a patient portal where patients log in, complete forms, and pay.

Every screen in both portals had to be built with HIPAA compliance in mind from the start, not bolted on afterward, since both portals handle real patient health information.

Key features

  • Provider-initiated blood test ordering
  • Prescription e-signature workflow
  • Fillable PDF intake and consent forms
  • Patient sign-in and online payment

Technical highlights

  • Built the front end to meet HIPAA compliance requirements throughout, from data handling to session security
  • Implemented e-signature workflows for prescriptions and generated fillable PDF forms for patient paperwork
  • Connected both portals to REST APIs and contributed to the C#/.NET backend supporting end-to-end healthcare workflows

My role

  • Lead front-end developer on both the patient and provider portals
  • Owned front-end architecture, implementation, testing, and release readiness
  • Worked directly with the backend team on API contracts and contributed to backend logic where needed
